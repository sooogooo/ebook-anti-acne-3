# 专业痤疮治疗指南 - 现代化UI界面

## 项目概述

这是一个为专业痤疮治疗指南电子书设计的现代化移动优先UI界面，具有女性化优雅设计风格和丰富的AI交互功能。

## 🌟 主要特性

### 📱 移动优先设计
- 完全响应式布局，适配手机、平板和PC设备
- iOS设备专门优化，确保完美兼容性
- 现代Web技术，流畅的动画和交互效果

### 🎨 女性化主题系统
- **玫瑰石英**：柔和温暖的粉色主题
- **鼠尾草绿**：清新自然的绿色主题
- **淡紫薰衣草**：优雅浪漫的紫色主题
- **蜜桃粉**：活力四射的橙色主题
- 支持深色模式自动适配

### 🤖 智能AI功能
- **AI咨询助手**：智能问答，个性化建议
- **划词AI**：选中文字即可获得解释和建议
- **自动问题生成**：基于对话内容智能生成相关问题
- **语音输入**：支持语音转文字输入（iOS优化）

### 📊 设计工具
- **个性化护肤方案**：根据皮肤类型和需求生成定制方案
- **可视化展示**：丰富的SVG图表和动画效果
- **报告导出**：支持PNG和PDF格式导出
- **历史记录**：保存和加载聊天记录及设计方案

### ⚙️ 个性化设置
- **主题配色**：4种优雅女性化主题可选
- **字号调节**：小、中、大三种字号
- **AI风格**：轻松幽默、标准日常、科学严谨
- **输出长度**：详细、标准、简约

## 🛠 技术架构

### 前端技术栈
- **HTML5**：语义化标记，现代化结构
- **CSS3**：Flexbox、Grid布局，CSS变量
- **JavaScript ES6+**：模块化开发，现代API
- **Web Fonts**：Inter + Noto Sans SC中文字体
- **Material Symbols**：现代图标系统

### 兼容性优化
- **iOS Safari**：专门优化，解决兼容性问题
- **Android Chrome**：全面支持
- **桌面浏览器**：Chrome、Firefox、Safari、Edge
- **响应式设计**：完美适配各种屏幕尺寸

## 🎯 核心功能详解

### 1. AI咨询助手
- 智能问答系统，提供专业的痤疮治疗建议
- 支持多种AI输出风格（轻松幽默、标准日常、科学严谨）
- 语音输入功能，特别优化iOS设备兼容性
- 自动生成追问问题，引导用户深入了解

### 2. 护肤方案设计器
- 根据皮肤类型（油性、干性、混合性、敏感性）定制方案
- 痤疮严重程度评估（1-5级）
- 多重需求选择（抗炎舒缓、控油保湿、淡化疤痕）
- 可视化方案展示，支持PNG/PDF导出

### 3. 划词AI功能
- 选中任意文字即可获得AI解释和建议
- 三种AI操作：解释、相关知识、建议
- 智能上下文理解，提供精准回复

### 4. 历史记录管理
- 聊天记录自动保存
- 设计方案历史追踪
- 一键清空和导出功能
- 支持JSON格式数据导出

## 🚀 使用方法

### 本地运行
```bash
# 进入项目目录
cd ui

# 使用任意HTTP服务器运行
python3 -m http.server 8000
# 或
npx serve .
# 或
live-server
```

访问 `http://localhost:8000` 即可查看界面。

### 部署到生产环境
1. 将所有文件上传到Web服务器
2. 确保服务器支持HTTPS（iOS设备要求）
3. 配置正确的MIME类型
4. 启用Gzip压缩优化加载速度

## 🔧 自定义配置

### 添加新主题
在 `assets/css/themes.css` 中添加新的主题变量：
```css
[data-theme="new-theme"] {
  --primary-color: #your-color;
  --primary-light: #your-light-color;
  /* 其他颜色变量 */
}
```

### 修改AI回复模板
在 `assets/js/main.js` 中的响应生成函数中添加新的回复模板。

### 自定义样式
通过修改CSS变量轻松调整颜色、间距、字体等样式。
