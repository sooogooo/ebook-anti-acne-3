    MkDocs 增强功能说明¶

    本文档说明了为痤疮治疗书籍添加的 MkDocs 增强功能。

    新增功能¶

    1. Mermaid 图表支持¶

    已添加完整的 Mermaid 图表支持，包括：

    • 流程图 - 展示治疗流程和决策树
    • 序列图 - 展示医患交互过程
    • 类图 - 展示痤疮分类和治疗方案结构
    • 饼图 - 展示治疗方法分布
    • 甘特图 - 展示治疗时间线
    • 状态图 - 展示痤疮发展过程

    使用方法： 

    ```mermaid
graph TD
    A[开始] --> B{痤疮类型判断}
    B -->|寻常痤疮| C[轻度治疗]
    B -->|中度痤疮| D[联合治疗]

    2. 增强的 Markdown 扩展¶

    已添加以下 Markdown 扩展：

    • 代码高亮增强 - 支持行号、锚点、语言类名
    • 数学公式 - 支持 LaTeX 数学公式
    • 任务列表 - 支持自定义复选框
    • 标签页 - 支持内容分组展示
    • 警告框 - 支持多种类型的提示信息
    • 表格增强 - 支持更复杂的表格格式
    • 缩写 - 支持缩写词
    • 代码片段 - 支持代码片段包含

    3. 移除 GitHub 相关内容¶

    已从配置中移除所有 GitHub 相关内容： - repo_name 和 repo_url 设置为 null - 移除 GitHub 社交媒体链接 - 移除 GitHub 相关的魔法链接配置

    4. 新增依赖项¶

    在 requirements.txt 中添加了以下依赖： - mkdocs-mermaid2-plugin - Mermaid 图表支持 - pymdown-extensions - 增强 Markdown 扩展 - pygments - 代码高亮支持

    5. 主题配置更新¶

    更新了 Material 主题配置： - 添加了 navigation.footer 功能 - 配置了 Mermaid 主题变量 - 优化了颜色方案

    使用示例¶

    数学公式示例¶

    $$ \text{GAGS Score} = \sum_{i=1}^{6} (F_i \times W_i) $$

    标签页示例¶

    === "外用药物"
- 维A酸类药物
- 抗生素类药物

=== "口服药物"
- 抗生素
- 异维A酸

    警告框示例¶

    !!! warning "警告"
    异维A酸有致畸性，孕妇禁用，育龄期女性需严格避孕。

    任务列表示例¶

    - [x] 完成基础诊断
- [ ] 开始外用药物治疗
- [ ] 安排复诊时间

    测试文件¶

    已创建 docs/mermaid-test.md 测试文件，包含所有新增功能的示例。

    构建和部署¶

    使用以下命令构建和部署：

    # 安装依赖
pip install -r requirements.txt

# 构建站点
mkdocs build

# 本地预览
mkdocs serve

    兼容性说明¶

    • 兼容 MkDocs >= 1.5.0
    • 兼容 Material for MkDocs >= 9.4.0
    • 使用最新的 Mermaid 10.6.1 版本
    • 避免使用已弃用的配置选项

    所有配置都经过测试，确保与当前版本的 MkDocs 和 Material 主题兼容。
