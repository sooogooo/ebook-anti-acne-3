    第三章 医生的基础武器——口服与外用药物¶

    在各种炫酷的光电医美项目大行其道的今天，很多人似乎对"药物治疗"有些不屑一顾，觉得它"老土"、"见效慢"，甚至因为对副作用的恐惧而敬而远之。这是一个极大的误区。

    请记住，作为一名严谨的皮肤科医生，我必须负责任地告诉你：规范化的药物治疗，是整个痤疮治疗体系的基石，是性价比最高、循证医学证据最充分的手段，没有之一。 依据《中国痤疮治疗指南（2019修订版）》，药物治疗是所有级别痤疮治疗的基础。任何跳过药物治疗，直接追求"高科技"猛药的行为，都可能本末倒置，让你付出不必要的金钱和时间成本。

    药物，特别是外用药，是绝大多数痤疮患者都应该首先尝试，并且需要在医生的指导下长期坚持的"随身武器"。

    重要提示

    本章内容基于《中国痤疮治疗指南（2019修订版）》和国际最新治疗标准。所有药物使用必须在专业医生指导下进行，切勿自行用药。

    3.1 药物治疗在痤疮管理中的核心地位¶

    在现代痤疮治疗体系中，药物治疗占据着不可替代的核心地位。它不仅是所有级别痤疮治疗的基础，更是后续各种医美治疗的前提和保障。

    性价比最高 相对较低的治疗成本 患者经济负担小 ⭐⭐⭐⭐⭐

    3.2 "小药膏"的大作用：外用药物的正确打开方式¶

    别小看医生给你开的这些药膏，它们每一个都不是"随便抹抹"的安慰剂，而是经过了大量临床试验验证的、能够针对痤疮四大发病机制中的某个或某几个环节进行精准打击的"精确制导导弹"。学会正确使用它们，是你在家进行自我治疗最重要的一环。

    外用药物的四大类武器¶

    药物类别 主要作用 适合症状 特点优势 注意事项
    维A酸类 疏通毛孔、抗炎 粉刺、炎性痤疮 治疗基础、多效合一 需建立耐受、避光使用
    壬二酸 抗炎、抗菌、美白 敏感肌、玫瑰痤疮 温和全面、改善痘印 初期可能有刺痛感
    过氧苯甲酰 杀菌、溶解粉刺 红肿痘痘、脓疱 强效杀菌、不耐药 刺激性、可能漂白衣物
    外用抗生素 抑菌、抗炎 炎性丘疹、脓疱 快速消炎 易耐药、需联合使用

    3.2.1 维A酸类（Topical Retinoids）——"管道疏通工"与"多面手"¶

    这是外用药中的"王牌家族"，是治疗**非炎性痤疮（粉刺）的首选，同时也是**炎性痤疮联合治疗**和**维持治疗**的核心药物。它们的核心作用，就是**纠正毛囊口的异常角化，相当于一位勤勤恳恳的"管道疏通工"，让堵塞的毛囊重新变得通畅，从源头上阻止微粉刺的形成。同时，它们还兼具溶解已有粉刺、抗炎、预防和改善色素沉着（痘印）、甚至促进胶原生成（长期使用）的多重功效。

    维A酸家族成员对比¶

    药物名称 世代特点 治疗强度 刺激性 适用人群 推荐指数
    阿达帕林凝胶 第三代 中等 较低 初次使用者、敏感肌 ⭐⭐⭐⭐⭐
    他扎罗汀凝胶 第三代 强效 较高 顽固性痤疮、耐受者 ⭐⭐⭐⭐
    维A酸乳膏 第一代 强效 较高 严重痤疮、非敏感肌 ⭐⭐⭐

    代表药物详情¶

    1. 阿达帕林凝胶（Adapalene） - 优势： 对受体的选择性更高，刺激性相对较小，光敏性也较低 - 地位： 目前最常用的一线药物，是很多人的入门首选

    2. 他扎罗汀凝胶/乳膏（Tazarotene） - 优势： 效果更强，适合顽固性痤疮 - 注意： 刺激性也最大，通常用于对阿达帕林反应不佳的患者

    3. 维A酸乳膏（Tretinoin） - 地位： 最经典的维A酸药物，效果确切 - 现状： 光敏性和刺激性都比较强，现在临床上已较少作为首选

    专家建议： 对于初次使用维A酸的患者，强烈推荐从阿达帕林开始，其良好的耐受性和确切的效果使其成为理想的首选药物。

    维A酸正确使用指南——"避光、少量、三明治、耐心"¶

    维A酸的正确使用方法直接关系到治疗效果和安全性。请遵循以下黄金法则：

    维A酸使用时间表¶
    使用阶段 频率安排 目标 预期反应 应对策略
    第1-2周 每2-3天一次 建立耐受 轻微干燥、脱皮 减少频率、加强保湿
    第3-4周 隔天一次 巩固耐受 症状减轻 继续观察、调整保湿
    第1个月后 每天一次 维持治疗 皮肤适应 标准维持方案
    具体使用步骤¶

    1. 夜间使用，严格避光 - 时间： 夜间、睡前关灯前使用 - 原因： 多数维A酸类药物具有光不稳定性，紫外线会使其分解失效 - 防晒： 白天必须做好严格防晒，否则可能加重皮肤刺激

    2. 从"米粒"大小开始 - 用量： 取**一粒米**大小的药膏 - 方法： 点涂在额头、鼻子、下巴、两颊五个区域，迅速均匀涂抹 - 范围： 覆盖整个容易长痘的区域（预防性使用） - 原则： 预防为主，而非等痘痘长出来再补救

    3. 建立皮肤耐受 维A酸最常见的副作用是引起皮肤干燥、脱皮、泛红、刺痛，我们称之为"A酸性皮炎"。避免方法：

    A酸性皮炎应对方案：
    • 初期使用频率要低，逐步增加
    • 配合强效保湿产品使用
    • 出现严重不适时暂停使用，待恢复后重新开始

    4. "三明治"涂抹法 这是一个非常有效的缓冲技巧，能显著降低刺激性：

    1. 第一层： 洁面后涂一层清爽保湿乳，等待完全吸收
    2. 第二层： 薄涂一层维A酸药膏
    3. 第三层： 几分钟后再涂一层保湿乳

    5. 耐心，耐心，再耐心！ - 起效时间： 需要**连续使用4-8周**才能看到粉刺初步改善 - 稳定效果： 3个月**以上效果才会比较明显和稳定 - **常见误区： 很多人在最初一两周的"不耐受期"就放弃，这是最可惜的

    医生悄悄话

    很多人会经历一个所谓的"爆痘期"，即使用初期，一些深埋在皮下的微粉刺被药物"催熟"，加速发展成炎性痘痘。这其实是药物起效的正常过程，是把"潜在的雷"提前排出来的表现。这个过程通常发生在2-4周，请一定不要惊慌，更不要放弃，坚持下去，就是"黎明前的黑暗"。

    3.2.2 壬二酸（Azelaic Acid）——温和的全能型选手¶

    如果你的皮肤非常敏感，尝试了各种方法都无法耐受维A酸，那么壬二酸是一个非常好的替代选择。它像一位性格温和但能力全面的战士，兼具**溶解粉刺、抗炎、抗菌、抑制色素（美白痘印）**四大功能。

    壬二酸的核心优势¶

    功能特点 作用机制 适合症状 特殊优势
    抗炎作用 抑制炎症因子产生 红肿痘痘 减轻炎症反应
    抗菌效果 抑制痤疮丙酸杆菌 感染性痤疮 不产生耐药性
    溶解粉刺 软化角质、疏通毛孔 闭口粉刺 温和不刺激
    美白祛印 抑制黑色素生成 炎症后色沉 改善黑痘印

    适用人群与使用建议¶

    特别适合： - 敏感性肌肤患者 - 玫瑰痤疮伴发丘疹脓疱 - 有明显炎症后色素沉着（黑痘印）的患者 - 孕妇（需医生指导）

    代表药物： 15%的壬二酸凝胶，20%的壬二酸乳膏

    使用方法： - 使用时间： 可早晚使用，光敏性很低 - 建立耐受： 同样建议从少量开始，逐步建立耐受 - 常见反应： 部分人使用初期会有短暂的、一过性的瘙痒或刺痛感 - 适应期： 通常在持续使用一两周后，随着皮肤适应会逐渐消失

    专家提示： 壬二酸是国际指南推荐的治疗玫瑰痤疮伴发丘疹脓疱的一线药物，对于敏感肌患者来说是理想的选择。

    3.2.3 过氧苯甲酰（Benzoyl Peroxide, BPO）——强效的"细菌定点清除专家"¶

    这是专门针对**炎性丘疹和脓疱**的"特种兵"。它的核心武器是释放出高活性的氧自由基，能迅速、高效地杀死毛囊里的痤疮丙酸杆菌，而且有一个巨大的优点：几乎不会产生耐药性。

    BPO浓度选择指南¶

    浓度 杀菌效果 刺激性 推荐用途 适用人群
    2.5% 优秀 较低 首选浓度 初次使用者、敏感肌
    5% 优秀 中等 顽固性痤疮 耐受性好的患者
    10% 优秀 较高 胸背部痤疮 严重痤疮、非敏感肌

    正确使用方法——"点涂、低浓度、防漂白"¶

    1. 点涂为主 - BPO具有一定的刺激性和干燥作用 - 面部通常建议**点涂**在红肿的炎性痘痘上 - 胸背部大面积痤疮可适当扩大使用范围

    2. 从低浓度开始 - 大量研究表明，2.5%的浓度在杀菌效果上与高浓度相差无几 - 但刺激性却小得多，永远建议从低浓度开始尝试

    3. 小心衣物漂白 - BPO具有氧化性，会让深色衣物、毛巾、枕套褪色 - 使用时要格外小心，建议使用白色或浅色枕套

    重要提醒： BPO常与抗生素联合使用，以降低后者的耐药风险，是联合治疗的重要组合。

    3.2.4 外用抗生素——速战速决但需警惕的"援军"¶

    主要用来抑制痤疮丙酸杆菌的生长，并发挥其抗炎作用，能快速地让红肿的痘痘"瘪下去"。

    外用抗生素使用原则——"联合、短期、不单独"¶

    耐药性问题： - 外用抗生素最大的问题是容易诱导细菌**耐药** - 一旦耐药，药物就彻底失效 - 所有治疗指南都强烈不建议长期、大面积地单独使用

    最佳联合策略¶

    联合药物 优势 推荐组合 使用方法
    过氧苯甲酰 降低耐药风险、增强效果 克林霉素 + BPO 复方制剂或分开使用

    使用期限： 即便联合使用，也建议外用抗生素的使用时间最好不超过12周

    3.3 口服药物的"王牌"与"时机"：何时需要启动"重武器"？¶

    当痤疮发展到**中重度（Ⅲ-Ⅳ级）**，表现为大量的炎性丘疹、脓疱，甚至出现了结节和囊肿；或者虽然皮损数量不多，但反复发作，有明显的留疤倾向；亦或者，规范的外用药物治疗3个月后效果依然不佳时——我们就必须考虑启动口服药物这些"重武器"了。

    口服药物治疗决策标准¶

    启用条件 具体表现 严重程度 治疗目标 推荐等级
    病情严重 大量炎性丘疹、脓疱、结节囊肿 Ⅲ-Ⅳ级 快速控制炎症 ⭐⭐⭐⭐⭐
    反复发作 周期性加重，影响生活质量 Ⅱ-Ⅳ级 预防复发 ⭐⭐⭐⭐
    留疤倾向 有疤痕形成风险 Ⅱ-Ⅳ级 预防疤痕 ⭐⭐⭐⭐⭐
    外用无效 规范治疗3个月效果不佳 Ⅱ-Ⅳ级 强化治疗 ⭐⭐⭐⭐

    口服药物治疗的核心目标¶

    3.3.1 口服抗生素——快速控制"火情"的消防队¶

    这是治疗中重度炎性痤疮最常用的一线口服药物。它们的作用并不仅仅是"杀菌"，在治疗痤疮时，我们更看重其强大的**抗炎作用**。它们能抑制中性粒细胞的趋化，减少炎症因子的释放，像一支高效的消防队，能快速控制住脸上的"大火灾"，让红肿热痛的皮损迅速得到缓解。

    口服抗生素分类与特点¶

    药物类别 代表药物 抗炎强度 脂溶性 耐药风险 推荐指数
    四环素类 多西环素、米诺环素 强 高 中等 ⭐⭐⭐⭐⭐
    大环内酯类 红霉素、阿奇霉素 中等 中等 较高 ⭐⭐⭐

    治疗原则——"足量、足疗程、不单用、不久用"¶

    1. 足量、足疗程 - 规律服用： 在医生指导下，规律、足量**地服用 - **避免间断： 不要因为症状改善就擅自停药，症状加重又重新服用 - 标准疗程： 一个标准的疗程通常是**6-12周**

    2. 联合外用药 - 必须联合： 口服抗生素**必须联合外用维A酸**，或者**过氧苯甲酰** - 双重优势： 提高疗效，显著降低耐药风险

    3. 避免长期使用 - 时间限制： 总疗程通常建议**不超过3个月** - 维持治疗： "火情"得到基本控制后，逐渐停掉抗生素，仅用外用药维持

    注意事项与副作用管理¶

    药物 主要注意事项 常见副作用 禁忌人群 监测要求
    多西环素 光敏性强、避免与牛奶同服 光敏反应、胃肠道不适 8岁以下儿童、孕妇 肝功能、光防护
    米诺环素 可能引起头晕、色素沉着 头晕、色沉、眩晕 前庭功能障碍患者 神经系统症状
    大环内酯类 胃肠道反应较多 腹泻、恶心 肝功能不全者 胃肠道症状
    重要提醒： 四环素类药物不能与牛奶同服（影响吸收），且禁用于8岁以下儿童和孕妇（影响牙齿和骨骼发育）。

    3.3.2 异维A酸（Isotretinoin）——力挽狂澜的"终极王牌"¶

    如果说抗生素是"消防队"，那么异维A酸就是"战区总司令"，是目前治疗**重度、囊肿结节性痤疮**最有效的药物，没有之一。我有时会跟我的患者形容它为"核武器"，因为它威力巨大，能同时作用于痤疮发病的**四大核心环节**。

    副作用管理——精细的艺术¶

    异维A酸的副作用管理是一门精细的艺术，需要医生和患者密切配合：

    1. 皮肤黏膜干燥（发生率：接近100%） - 表现： 嘴唇干裂、皮肤干燥、眼干、鼻腔干燥 - 对策： - 从服药第一天起随身携带**润唇膏**（凡士林、依泉、理肤泉B5唇膏等） - 使用比平时更滋润、更温和的保湿修复产品 - 可使用不含防腐剂的人工泪液缓解眼干

    2. 致畸性（最严重副作用） - 风险： 明确的、强烈的致畸性 - 避孕要求： - 育龄期女性： 服药前1个月、服药期间、停药后至少3个月内严格避孕 - 避孕方式： 必须采取**两种可靠**的避孕措施 - 监测： 治疗前、治疗期间每月检查血或尿妊娠试验（hCG）

    3. 肝功能与血脂影响 - 风险： 少数患者可能出现转氨酶升高和血脂升高 - 监测： 服药前及服药后1-2个月定期复查肝功能和血脂 - 管理： 避免饮酒，减少高脂饮食

    4. 其他罕见副作用 - 可能症状： 情绪波动、肌肉关节疼痛、夜视力下降等 - 特点： 绝大多数副作用都与剂量相关，停药后可逆

    医生手记： 我深知很多人对异维A酸怀有巨大的恐惧，网络上关于它的"恐怖故事"也流传甚广。但作为一名专业的医生，我们之所以敢于使用这个"核武器"，是因为我们对它的"威力"和"脾气"了如指掌，并且有一整套成熟的监测和管理方案。 关键事实： - 只要在专业医生的严密监测和指导下，副作用是完全可控的 - 相较于可控可逆的副作用，任由重度痤疮发展留下的永久性疤痕和心理创伤伤害更大 - 对于符合适应症的患者，它是扭转战局、重获新生的最强盟友

    3.3.3 抗雄激素治疗——专门针对女性的"精准内分泌调控"¶

    对于一部分成年女性痤疮，问题的核心出在了内分泌上。她们可能血液中的雄激素水平偏高（如PCOS患者），或者激素水平正常但皮脂腺对雄激素的反应过于"热情"。对于这类患者，抗雄激素治疗是一条非常有效的"釜底抽薪"的路径。

    短效避孕药使用要点： - 必须在医生详细评估后使用 - 有完整的适应症和禁忌症评估流程 - 需关注血栓风险，特别是吸烟女性

    专家提示： 抗雄激素治疗是针对女性痤疮的重要手段，但必须在专业医生指导下进行，需要严格的评估和监测。
