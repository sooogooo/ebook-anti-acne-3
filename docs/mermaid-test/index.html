    代码块增强功能测试¶

    # 痤疮严重程度评估算法
def acne_severity_assessment(comedones, papules, pustules, nodules):
    """
    根据皮损数量评估痤疮严重程度
    """
    total_lesions = comedones + papules + pustules + nodules

    if total_lesions <= 10:
        return "轻度"
    elif total_lesions <= 30:
        return "中度"
    elif total_lesions <= 50:
        return "中重度"
    else:
        return "重度"

# 示例使用
severity = acne_severity_assessment(5, 8, 3, 1)
print(f"痤疮严重程度: {severity}")

    警告框测试¶

    注意事项

    外用维A酸可能会引起皮肤干燥和刺激，建议从低浓度开始使用。

    警告

    异维A酸有致畸性，孕妇禁用，育龄期女性需严格避孕。

    危险

    不要自行挤压痘痘，可能导致感染扩散和疤痕形成。

    小贴士

    保持规律作息和健康饮食对改善痤疮有重要作用。

    数学公式测试¶

    痤严重程度评分公式：

    \[ \text{GAGS Score} = \sum_{i=1}^{6} (F_i \times W_i) \]

    其中： - \(F_i\) = 第 \(i\) 个区域的皮损评分 - \(W_i\) = 第 \(i\) 个区域的权重系数

    皮脂分泌率计算：

    \[ \text{Sebum Excretion Rate} = \frac{\text{Total Sebum}}{\text{Surface Area} \times \text{Time}} \]
